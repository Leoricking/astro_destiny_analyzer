# Astro Destiny Analyzer — Demo 展示指南

## Demo 目標

展示**東西方命盤整合分析系統**的完整功能：
- 多命理系統交叉分析
- 透明的計算模式說明
- 多格式報告匯出
- 自我探索與人格敘事工具

---

## 推薦 Demo 流程（約 5 分鐘）

### Step 1：開啟首頁

啟動後展示：
- 系統支援的 5 個命理模組
- 快速體驗按鈕

**重點說明**：「這不是單一星座工具，而是多系統交叉驗證。」

---

### Step 2：載入 Demo 資料

點選首頁「**💼 Demo 新竹科技職涯**」

此範例特點：
- 出生日期：1989-09-21，出生時間：11:05
- 主題：事業、財富、個人年運
- 報告長度：萬字完整版

---

### Step 3：計算命盤

前往「🔮 計算命盤」→ 點「開始計算命盤」

計算完成後可展示四個分頁：

#### 🌟 西洋占星
重點展示：
- 太陽星座 / 月亮星座 / 上升星座 (ASC) / 天頂 (MC)
- 行星位置詳表
- calculation_mode（swiss_ephemeris / partial_real）
- accuracy_note 說明精確度

**講解話術**：「每個指標都附有計算模式說明，缺資料時不假裝精準。」

#### ☯️ 八字
重點展示：
- 四柱（年柱以立春切年，月柱以節令切月）
- 日主與喜用神
- 五行比例

**講解話術**：「節氣計算精確到小時，不是用農曆簡單估算。」

#### 🏮 紫微斗數
重點展示：
- 命宮 / 身宮 / 五行局
- 十四主星分布
- 生年四化
- 大限（10 年運限骨架）

**講解話術**：「紫微 Phase 1 已有完整骨架，輔星 / 大限都已就位。」

#### 🔢 生命靈數
- 生命靈數、天賦數、個人年運

---

### Step 4：報告預覽

前往「📄 報告預覽」

展示：
- 頂部摘要卡（姓名、版本、計算模式）
- 整合分析互動式模式
- 核心人格 / 感情 / 事業 / 財富各章節

---

### Step 5：匯出

前往「📤 匯出」

推薦展示：
- 下載 HTML → 雙擊開啟，展示美化版排版
- 展示封面、免責聲明、計算模式摘要、一頁式總覽、目錄、正文

---

## 推薦講解話術

| 情境 | 話術 |
|------|------|
| 開場 | 「這是一套多系統命盤整合分析工具，同時跑西洋、八字、紫微三套系統。」 |
| 展示精確度 | 「每個計算模式都有明確說明，缺資料不冒充精準。」 |
| 展示報告 | 「報告自動整合五套系統，找出共同主題，也標出矛盾之處。」 |
| 談限制 | 「這是娛樂參考工具，不是算命，不做任何科學、醫療、法律主張。」 |

---

## 展示時注意事項

1. **不宣稱科學定論**：所有分析結果均為自我探索參考。
2. **不做醫療 / 法律 / 投資建議**：請在報告中確認免責聲明已顯示。
3. **強調自我探索**：定位為人格理解工具，而非命運斷定。
4. **說明 Phase 1**：紫微大限 / 輔星為 Phase 1，尚未有流年飛化等進階功能。
