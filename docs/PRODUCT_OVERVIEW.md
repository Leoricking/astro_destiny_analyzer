# Astro Destiny Analyzer — 產品概覽

## 產品名稱

**Astro Destiny Analyzer**（命盤整合分析系統）

---

## 產品定位

**東西方命盤整合分析系統**

將西洋占星、八字命理、紫微斗數、血型分析與生命靈數整合為一份完整的個人命盤報告。
強調透明計算模式、跨系統交叉驗證，以及清楚的精確度說明。

---

## 核心功能

### 命理引擎

| 模組 | 功能 |
|------|------|
| 🌟 西洋占星 | Swiss Ephemeris 精確行星計算、宮位、相位、上升 (ASC)、天頂 (MC) |
| ☯️ 八字命理 | 節氣精確切年切月、四柱、五行比例、日主、喜用神、大運、流年 |
| 🏮 紫微斗數 | 農曆轉換、命宮 / 身宮 / 五行局、十四主星、生年四化、輔星 / 煞星、大限 Phase 1 |
| 🩸 血型分析 | 人際、感情、職場、財富輔助分析（A / B / O / AB / Unknown） |
| 🔢 生命靈數 | 生命靈數、生日數、天賦數、個人年運，大師數 11 / 22 / 33 保留 |

### Synthesis Engine

跨系統整合分析，自動：
- 整合五套系統的核心主題
- 偵測跨系統矛盾並提出解釋
- 生成感情、事業、財富、人際、壓力與陰影、流年趨勢、行動建議

### 報告系統

- 三種長度：簡短版（~800 字）、標準版（~3,000 字）、萬字完整版（~10,000 字）
- Jinja2 模板，支援繁體中文 / 簡體中文 / English
- 封面、免責聲明、基本資料、計算模式摘要、一頁式總覽、目錄、正文

### 匯出格式

| 格式 | 說明 |
|------|------|
| Markdown | 適合二次編輯與版本控制 |
| HTML | 自含 CSS、適合展示與列印，支援繁體中文字型 |
| Word (.docx) | 適合客戶交付，需 python-docx |
| PDF | 選用，需 WeasyPrint |

## 差異化特點

### 不只是太陽星座

絕大多數占星工具只看太陽星座。本系統計算完整星盤（10+ 行星、12 宮位、主要相位）。

### 多系統交叉驗證

同時跑西洋、八字、紫微三套系統，找出共同主題，也標出矛盾。

### 透明的計算精確度

每個子系統均有 `calculation_mode` 和 `accuracy_note`：
- `swiss_ephemeris`：精確模式
- `partial_real`：部分精確（缺出生時間或座標）
- `mock_fallback`：後備模式（缺套件時不 crash）

**缺資料時不假裝精準。**

### 可交付的完整報告

HTML 報告含封面、目錄、計算模式摘要、一頁式總覽，可直接發送給客戶。

## 適合用途

- **自我探索**：深度了解自己的人格模式與行為傾向
- **情感理解**：感情模式、溝通風格、相處課題
- **職涯思考**：優勢方向、事業主題、壓力來源
- **顧問報告**：命理顧問工具，快速生成專業格式報告
- **產品展示 / Demo**：展示多系統整合能力
