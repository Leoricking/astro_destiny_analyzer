# Astro Destiny Analyzer — 快速上手指南

## 這是什麼？

**Astro Destiny Analyzer** 是一套東西方命盤整合分析系統，結合：
- 🌟 西洋占星（Swiss Ephemeris）
- ☯️ 八字命理（節氣精確計算）
- 🏮 紫微斗數（正式排盤 Phase 1）
- 🩸 血型分析
- 🔢 生命靈數

一次輸入出生資料，自動生成數千字個人化分析報告，可匯出 HTML / Word / Markdown。

---

## 第一次使用

**雙擊 `setup.bat`**

自動完成：
1. 檢查 Python 版本
2. 建立虛擬環境 `.venv`
3. 安裝所有套件（`requirements.txt`）
4. 執行環境檢查

> 需要 Python 3.10+。請至 https://www.python.org/downloads/ 下載。

---

## 日常啟動

**雙擊 `run.bat`**

自動：
1. 確認環境
2. 更新套件
3. 啟動 Streamlit 應用程式
4. 自動開啟瀏覽器 → http://localhost:8501

---

## 三分鐘快速體驗

1. 雙擊 `run.bat` 啟動
2. 首頁點選「**💼 Demo 新竹科技職涯**」
3. 跳轉「🔮 計算命盤」→ 點「**開始計算命盤**」
4. 前往「**📄 報告預覽**」閱讀分析
5. 前往「**📤 匯出**」下載 HTML 報告
6. 雙擊開啟 HTML 檔案即可閱讀完整報告

---

## 使用自己的資料

1. 點側欄「**📝 輸入資料**」
2. 填寫：
   - **姓名**（可用暱稱）
   - **出生日期**（西元年月日）
   - **出生時間**（出生時間越準，上升星座越精確）
   - **出生城市**（選台灣城市可自動帶入經緯度）
3. 點「✅ 確認資料」
4. 前往「🔮 計算命盤」

> 沒有出生時間也可以使用，但上升星座 (ASC) 和天頂 (MC) 將無法精確計算。

## 常見問題

**Q: 找不到 Python？**  
A: 請至 https://www.python.org/downloads/ 安裝 Python 3.10+。
安裝時勾選「Add Python to PATH」。

**Q: PDF 下載顯示「未安裝」？**  
A: PDF 為選用功能。執行 `pip install weasyprint`（Windows 可能需要額外依賴）。
建議優先使用 HTML 或 Word。

**Q: PowerShell 顯示 Execution Policy 錯誤？**  
A: `run.bat` 不使用 `activate.ps1`，不受 PowerShell 執行政策影響。
無需修改系統設定，直接雙擊 `run.bat` 即可。

**Q: 上升星座顯示「需補充資料」？**  
A: 精確計算 ASC / MC 需要同時具備「精確出生時間」和「出生地經緯度」。
請在輸入頁填寫出生時間，並選擇台灣城市（系統自動帶入座標）。
